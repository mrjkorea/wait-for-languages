Each redirect adds:

- `utm_source` = channel slug (`ig`, `tt`, `yt`, …)
- `utm_medium` = `social`
- `utm_campaign` = `wfl_signup`

The landing page forwards any `utm_*` query parameters to the Kit signup URL when visitors click **Get the free weekly tip**.
